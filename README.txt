【更新時の注意】
更新前に旧版の設定画面からJSONバックアップを保存してください。
既存の保存データは同じブラウザ・同じURLで引き継がれます。
違うURLや端末へ移す場合はJSONファイルを復元してください。
初回更新時、従来のローズテーマはハニーイエローに切り替わります。他のテーマは維持します。
ホーム画面のアイコンが古いままの場合、いったんホーム画面から削除し再追加してください。
